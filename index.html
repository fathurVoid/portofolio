Technical Implementation

CampusTask was developed using modern web development tools and practices. The following technologies were used throughout the development process.

Git and GitHub

Git is a distributed version control system used to track source code changes. GitHub hosts the repository and supports collaboration through branches and pull requests. Development involved creating branches, committing changes, merging pull requests, and resolving merge conflicts.

npm

npm is a package manager used to install and manage project dependencies. The package.json file defines dependencies, development dependencies, and scripts such as development, type checking, and production builds.

TypeScript

TypeScript extends JavaScript with static typing. CampusTask uses primitive types, arrays, interfaces, type aliases, union types, and generics to improve code reliability and maintainability.

Vite

Vite provides the local development server and production build process. It offers fast development feedback and processes application modules and assets for deployment.

Compiler, Transpiler, and Bundler

The TypeScript compiler (tsc) checks types and reports errors before production builds. TypeScript is also transformed into JavaScript. Vite uses its build pipeline to bundle application modules and assets into optimized production files.

Environment Variables

Environment variables separate application configuration from source code. CampusTask uses variables such as VITE_APP_NAME, VITE_APP_VERSION, VITE_APP_ENV, and VITE_BASE_PATH. The .env.example file documents the required configuration, while the local .env file is excluded from Git.
